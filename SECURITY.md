# Security Policy

## Supported Versions

We release patches for security vulnerabilities in the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

Only the latest minor version of each major release gets security updates.  
We strongly recommend updating to `5.1.x` for all security fixes.

## Reporting a Vulnerability

We take the security of PRECIOUS-MD seriously. If you discover a security vulnerability, please report it responsibly.

**How to report:**
1.  Do NOT open a public GitHub issue.
2.  Email us at: `fourpencewatson7@gmail.com` 
    Or DM the owner on WhatsApp: `+263781330745`
3.  Include: Description, Steps to reproduce, Affected version, Potential impact

**What to expect:**
- **Acknowledgement**: We will acknowledge receipt within 48 hours.
- **Updates**: You will get an update every 7 days on the status of your report.
- **Fix Timeline**: Critical vulnerabilities will be patched within 14 days. High/Medium within 30 days.
- **Disclosure**: After a fix is released, we will publicly credit you unless you request anonymity.

**What happens next:**
- **Accepted**: If accepted, we will work with you to release a patch. You will be credited in the release notes.
- **Declined**: If declined, we will explain why and may suggest an alternative fix.

Please give us time to fix the issue before making it public.

Thank you for helping keep PRECIOUS-MD safe!
